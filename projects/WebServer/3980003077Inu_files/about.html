Programming: The Beginning

Really; All you need is a text editor, a way to build your program, compile it, and then run it.
Today(2024), there are a lot of programs out there that can serve these purposes for you. However, not all of them will be covered here.
The main ones covered here will be (Visual Studio Code) + (Visual Studio 2022).
The purpose of covering these two specifically are due to the support between the two programs, but also as well the support for crossplatform Operating Systems(OS) such as, Windows, Linux, and MacOS enviornments.
This will allow for users to program on multiple Operating Systems(OS), giving them a more linent ways of running their projects.
Both programs support ways of writing in multiple languages, C++ | Python | HTTP | JS. Extentions and File=Path names just need to be installed and changed on your system specifically in order for programs to function properly.
(Setting It Up, However!!! Can sometimes be the daunting part.)

The basics should be simple, choose either (VS 2022) or (VS Code), as coders, programmers, refer to them.

Choose (Visual Studio 2022) if you run directly on a Windows Enviornment. (If you are an unsure User.)
This is due to Visual Studio mainly being a Windows created Application and 99% of standard users out there generally have a Windows machine.

Or

Choose (Visual Studio Code) if you run directly on a Linux / MacOS Enviornment. (More Experienced Users.)
Note: You can also use Visual Studio Code on Windows if you prefer it over the other.

Install it to a directory suitable for you. Every drive, computer is setup differently.
Write down your file=path names you install the program to. Example: C:/program files/etc.
Start learning your IDE, as you will be referring to it for EVERY project you work on.
You should now have a blank running application where you are able to create new projects.
