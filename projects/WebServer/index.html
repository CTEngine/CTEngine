CTEngine - Creating games | programs to learn.

CTEngine was created by myself (ARM&), as a way to learn how to program. I chose to start my journey with Python and then moved onto C++ once a bit of understanding was achieved in Python. While doing so, I found a nitch and understanding of language itself and decided to create this site and put it on Github for others like me that would like to learn this information for themselves on their time.
